
# 🐒 hacking-monkey

> 给猴子一台打字机，它迟早能敲出你的下一段灵感。

这是一个基于 **GUID 永久标识** 和 **分层文件系统** 的创意素材仓库。每一则灵感、人设、场景、对白都被切割成独立的“切片”，用 UUID v4 作为唯一身份证，通过 `href` 建立永不腐化的关联网络。

## 设计哲学

- **身份即地址**：每个切片 GUID 唯一，路径固定，URL 永不改变。
- **关联即链接**：切片间通过 `<a href="...">` 引用，形成知识图谱。

## 快速开始

### 创建新切片

在子仓库根目录下运行脚本：

```powershell
./utils/new.ps1
```

脚本会自动：

1. 生成一个新的 UUID v4
2. 在 `src/` 下创建分层目录（如 `src/34/`）
3. 用 UUID 剩余部分作为文件名（如 `5678...md`）
4. 生成包含元数据（标题、作者、创建时间）的 Markdown 模板

### 引用已有切片

在任意 Markdown 中，使用相对路径或绝对路径链接：

```markdown
参见 <a href="/src.html?uuid=xxxxxxxx-xxxx-4xxx-xxxx-xxxxxxxxxxxx">这个角色设定</a>。
```
